# Random Name Picker

Eine einfache React-Anwendung zur zufälligen Auswahl von Namen aus einer Liste. Die Anwendung kann beispielsweise im Unterricht verwendet werden, um zufällig Schülerinnen und Schüler auszuwählen.

## Funktionen

* Anzeige einer Namensliste
* Zufällige Auswahl eines Namens
* Einfache und übersichtliche Benutzeroberfläche

## Technologien

* React
* Vite
* JavaScript

## Installation

```bash
npm install
npm run dev
```

## Ziel des Projekts

Ziel des Projekts ist es, den Umgang mit React-Komponenten, State Management und Benutzerinteraktionen zu üben.
